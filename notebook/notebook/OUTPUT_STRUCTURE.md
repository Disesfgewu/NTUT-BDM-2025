# Output Directory Structure Documentation

## 📁 Directory Organization

All outputs are automatically organized into the following structure:

```
outputs/
├── charts/          # All visualization files (PNG & JPG)
├── reports/         # All CSV and text reports
└── raw_data/        # Raw data exports and statistics
```

## 📊 Output Files

### 1. Charts Directory (`outputs/charts/`)

All charts are saved in **both PNG and JPG** formats with timestamp.

#### Raw Data Visualizations:
- `raw_data_analysis_{timestamp}.png/.jpg`
  - 6-panel visualization:
    - Feature mean distribution
    - Feature std distribution
    - Timbre heatmap (first 100 songs)
    - Feature correlation matrix
    - Feature distribution box plot
    - Feature vector magnitude distribution

#### Recommendation System Visualizations:
- `diversity_comparison_{timestamp}.png/.jpg`
  - ILD (Intra-List Diversity) comparison bar chart
  - Compares Cosine, MMR, MMR+Temp methods
  
- `radar_chart_{timestamp}.png/.jpg`
  - 4-dimensional comparison (Relevance, Diversity, Novelty, Coverage)
  - Shows all 5 recommendation methods
  
- `weighted_score_ranking_{timestamp}.png/.jpg`
  - Horizontal bar chart of final rankings
  - Weighted composite scores
  
- `comprehensive_analysis_dashboard_{timestamp}.png/.jpg`
  - 6-panel comprehensive dashboard:
    1. Performance heatmap
    2. Grouped bar chart
    3. Box plot distribution
    4. Improvement vs baseline
    5. Relevance vs Diversity scatter plot
    6. Final weighted score ranking

**Chart Specifications:**
- Resolution: 300 DPI (publication quality)
- PNG: Lossless compression
- JPG: 95% quality (minimal compression)

---

### 2. Reports Directory (`outputs/reports/`)

All CSV reports with timestamp for version control.

#### Recommendation System Reports:
- `recommendation_performance_{timestamp}.csv`
  - Main results table
  - All 5 methods × 5 metrics (Relevance, Diversity, Novelty, Coverage, Weighted_Score)
  
- `statistical_summary_{timestamp}.csv`
  - Descriptive statistics for each metric
  - Mean, Std, Min, Max, Range
  
- `improvement_analysis_{timestamp}.csv`
  - Percentage improvement vs baseline (Cosine)
  - All methods compared to baseline
  
- `detailed_ranking_{timestamp}.csv`
  - Complete ranking with all metrics
  - Sorted by weighted score

#### Raw Data Report:
- `raw_data_statistics_{timestamp}.txt`
  - Comprehensive text report
  - Dataset overview
  - Feature statistics (12 timbre dimensions)
  - Data quality checks
  - Sample song IDs

---

### 3. Raw Data Directory (`outputs/raw_data/`)

#### Raw Feature Data:
- `song_features_{timestamp}.csv`
  - Complete feature matrix
  - 10,000 songs × 24 features
  - Columns: timbre_mean_1 to timbre_mean_12, timbre_std_1 to timbre_std_12
  - Index: song_id
  
- `feature_summary_statistics_{timestamp}.csv`
  - Summary statistics for all 24 features
  - Generated by pandas.describe()
  - Count, mean, std, min, 25%, 50%, 75%, max

## 🔄 Workflow

### Step 1: Setup (Cell 2)
```python
# Creates output directories and sets timestamp
OUTPUT_BASE_DIR = './outputs'
REPORTS_DIR = './outputs/reports'
CHARTS_DIR = './outputs/charts'
RAW_DATA_DIR = './outputs/raw_data'
RUN_TIMESTAMP = 'YYYYMMDD_HHMMSS'
```

### Step 2: Raw Data Analysis (Cells 10-12)
1. **Cell 10**: Generate raw data statistics report → `raw_data_statistics_{timestamp}.txt`
2. **Cell 11**: Create 6-panel visualization → `raw_data_analysis_{timestamp}.png/.jpg`
3. **Cell 12**: Export feature matrix → `song_features_{timestamp}.csv` + `feature_summary_statistics_{timestamp}.csv`

### Step 3: Recommendation System Evaluation
4. **Cell 29**: Diversity comparison → `diversity_comparison_{timestamp}.png/.jpg`
5. **Cell 40**: Radar chart → `radar_chart_{timestamp}.png/.jpg`
6. **Cell 42**: Weighted ranking → `weighted_score_ranking_{timestamp}.png/.jpg`
7. **Cell 46**: Comprehensive dashboard → `comprehensive_analysis_dashboard_{timestamp}.png/.jpg`
8. **Cell 48**: Export all CSV reports → 4 files in `reports/`

---

## 📋 File Naming Convention

**Format**: `{description}_{timestamp}.{extension}`

**Timestamp Format**: `YYYYMMDD_HHMMSS`
- Example: `20251209_143052`

**Extensions**:
- Charts: `.png` and `.jpg`
- Reports: `.csv`
- Raw data text report: `.txt`

## ✅ Benefits

1. **Organization**: All outputs in dedicated directories
2. **Version Control**: Timestamps prevent overwriting

## 🔧 Customization

To change output directories, modify Cell 2:

OUTPUT_BASE_DIR = './my_custom_outputs'
